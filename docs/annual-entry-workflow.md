# หน้ากรอกและนำเข้าข้อมูลปีงบประมาณ 2570

รุ่น 1.88 · 17 ตุลาคม 2569 · Apiwat Meethong

## เปิดใช้งาน

เข้าสู่ระบบเจ้าหน้าที่ → **กรอก / นำเข้าปี 2570** (`#annual-entry`) หรือ จัดการข้อมูล → ข้อมูลและสถิติ → เปิดหน้ากรอก / นำเข้า / เปรียบเทียบ

ADMIN เลือกหน่วยได้ตามสิทธิ์ STAFF เห็นเฉพาะหน่วยที่ได้รับมอบหมาย ผู้ไม่เข้าสู่ระบบ/บัญชีที่ไม่มีสิทธิ์หน่วยไม่สามารถกรอกผ่านหน้านี้ได้ การบันทึกยังตรวจ RLS และเก็บ Audit Log ในฐานเดิม

## แนวทางออกแบบ

1. เลือกหน่วย → ปีที่บันทึก → หมวด → เดือนสำหรับข้อมูลรายเดือน
2. ตารางเดียวแสดง **2569 อ้างอิง / 2570 บันทึกจริง / ผลต่าง** ข้อมูลรายเดือนเทียบเดือนเดียวกันของสองปี ไม่เทียบทั้งปีกับยอดสะสมบางเดือน
3. “—” หมายถึงยังไม่มีข้อมูล ไม่ใช่ศูนย์ ช่องว่างจะไม่ถูกแปลงเป็น 0
4. ข้อมูลพื้นฐานประจำปีมีปุ่มนำตัวเลขปีก่อนมาใส่เพื่อ **ตรวจและปรับก่อนบันทึก** ไม่คัดลอกทั้งปีอัตโนมัติ ผลงานรายเดือนไม่มีปุ่มยกตัวเลขปีก่อนเป็นผลงานปีใหม่
5. บันทึกแล้วเชื่อมตารางเดิมที่หน้าภาพรวม/ข้อมูลหน่วยบริการ/โรค/สถิติใช้อยู่ ไม่สร้างตารางเก็บตัวเลขซ้ำ
6. ปุ่มดูภาพรวม ดูยอดเงิน และตรวจทะเบียนปีก่อน ส่งต่อปีที่เลือกให้หน้าที่เกี่ยวข้อง แต่ไม่เปลี่ยนค่าปีหลักที่ ADMIN เคยกำหนด

## หมวดที่กรอกและนำเข้าได้

| หมวด | ความถี่ | ตัวเลข |
|---|---|---|
| ประชากรและพื้นที่ | ประจำปี | รวม ชาย หญิง หลังคาเรือน ชุมชน |
| อสม. | ประจำปี | จำนวน อสม. |
| บุคลากรแยกวิชาชีพ | ประจำปี | บุคลากรและสนับสนุน |
| NCD | รายเดือน | จำนวนราย แยกโรคและรายเก่า/รายใหม่ |
| โรคติดต่อ | รายเดือน | จำนวนราย แยกโรค |
| สถิติบริการอื่น | รายเดือน | จำนวนครั้ง แยกบริการ |

การเงินปี 2570 ใช้ **ติดตามแผนใช้เงิน** เป็นต้นทางเดิมเพียงแห่งเดียว หน้านี้เชื่อมไปบันทึกและดูยอดเงินตามปี ไม่เพิ่มจุดกรอกยอดซ้ำ ข้อมูล HDC ยังคงอ่านจาก HDC หน้านี้ไม่กรอกผลแทนต้นทาง HDC และไม่เปลี่ยนการพักการแสดง KPI จนกว่าผู้ดูแลตรวจข้อมูล

ทะเบียนบุคลากร ชื่อ รูป ฉ.11 และทะเบียนลา ใช้เมนูเจ้าหน้าที่ที่มีอยู่เดิม หน้านี้ดูแลสถิติหน่วยบริการ ไม่เปลี่ยนแบบราชการหรือระบบรับส่งเจ้าหน้าที่

## กรอกข้อมูล

กดกรอก/แก้ไข → ดูค่าปีก่อนข้างช่องกรอก → กรอกค่าที่ตรวจแล้ว → ติ๊กยืนยันปีและตัวเลข → บันทึก

- จำนวนเป็นจำนวนเต็มไม่ติดลบ ชาย + หญิงต้องเท่ากับรวมเมื่อกรอกครบสามช่อง
- หากปีปัจจุบันมีรายการซ้ำ จะไม่เดาว่าควรแก้รายการใด ให้ตรวจทะเบียนเดิมก่อน
- หากปีก่อนมีหลายรายการในกลุ่มเดียวกัน จะไม่รวมซ้ำเป็นค่าอ้างอิง แต่ยังบันทึกผลงานปีใหม่ที่ตรวจแล้วได้
- หากมีผู้แก้ก่อน ระบบหยุดและให้โหลดข้อมูลตรวจใหม่ ใช้ `updated_at` และเงื่อนไขหน่วย/ปีในการบันทึก

## CSV

1. เลือกหน่วย ปี หมวด และเดือนก่อนดาวน์โหลดแม่แบบ
2. ดาวน์โหลด **แม่แบบพร้อมค่าอ้างอิง** แม่แบบมีค่าปัจจุบันที่บันทึกไว้แล้ว และ `reference_*` สำหรับดูค่าปีก่อน
3. กรอกตัวเลขที่ตรวจแล้ว เก็บคอลัมน์ตามแม่แบบครบ ใช้ CSV UTF-8 และวันที่รูปแบบ `YYYY-MM-01` ตัวอย่างตุลาคมปีงบ 2570 คือ `2026-10-01`
4. กดนำเข้า CSV / ตรวจแฟ้ม ดูรายการเพิ่ม แก้ไข เหมือนเดิม และรายการที่ต้องตรวจ
5. รายการแก้ไขจะไม่ถูกเลือกให้อัตโนมัติ เปิดดูค่าก่อน/หลัง เลือกเฉพาะที่ต้องการ แล้วติ๊กยืนยันก่อนบันทึก

CSV ไม่เกิน 1 MB และ 300 แถวต่อครั้ง จำกัดหน่วย/ปี/เดือนตามหน้า คอลัมน์ `reference_*` ไม่ถูกบันทึกเป็นข้อมูลปีใหม่ ช่องว่างในคอลัมน์ตัวเลขที่นำเข้าจะเป็นค่าที่ยังไม่ทราบ จึงควรใช้แม่แบบที่มีค่าปัจจุบันและไม่ลบตัวเลขเดิมที่ต้องการเก็บไว้

การนำเข้าบันทึกแยกทีละรายการ หากบางรายการผิดพลาดจะแจ้งจำนวนที่สำเร็จและหยุดให้ตรวจใหม่ รายการที่สำเร็จแล้วไม่ถูกย้อนกลับทั้งหมด การตรวจแฟ้มซ้ำจะจำแนกค่าที่เหมือนเดิมเป็น “เหมือนเดิม” ไม่เพิ่มซ้ำโดยอัตโนมัติ

มีปุ่ม **ส่งออกตารางเปรียบเทียบ** สำหรับตรวจ/จัดทำรายงาน แฟ้มเปรียบเทียบมีคอลัมน์สองปีและผลต่าง แยกจากแม่แบบนำเข้า

## ตรวจสอบก่อนเผยแพร่

- JavaScript 171 tests ผ่าน รวม 10 tests ใหม่ของปีงบ ช่องว่าง/ศูนย์ CSV และการเทียบเดือน
- Browser 10 flows ผ่าน: จำกัดหน่วย อ้างอิงต้องเลือกเอง ไม่แก้ปีก่อน แม่แบบ CSV การเลือกรายการแก้ไข ตรวจยืนยัน ศูนย์ การแก้พร้อมกัน และผลนำเข้าได้บางส่วน
- ทดสอบบนฐาน cloud 18 checks ใน 6 หมวด: บันทึกหน่วยตนเองได้ แก้หน่วยอื่นไม่ได้ และข้อมูลอ้างอิงปีก่อนไม่เปลี่ยน ทั้งหมด rollback
- ตรวจ route ของแอปจริง เมนูใหม่และการกั้นผู้ไม่เข้าสู่ระบบผ่าน ไม่มี page error
- ไม่มีการนำตัวเลขสมมติหรือคัดลอกข้อมูลจริงปี 2569 เข้าปี 2570 ในการพัฒนาครั้งนี้
- ใช้ตารางเดิม ไม่มีตาราง/Storage ใหม่ Security advisors คงเดิม 29 INFO และ 1 WARN

ลำดับใช้งานที่เสนอ: ตรวจประชากร/พื้นที่และ อสม. ก่อน → ตรวจบุคลากรแยกวิชาชีพ → กรอกผลงานเดือนตุลาคม → ตรวจตารางเปรียบเทียบ → ตรวจความพร้อม HDC และให้ ADMIN กำหนดปีหลักตามแผนเดิม
