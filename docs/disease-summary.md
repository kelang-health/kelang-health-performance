# กล่องสรุปและการคืนอัตราโรค Ver.1.16

สาเหตุเดิม: CD rate model กำหนดให้มีรายการโรคจากทุกหน่วยในแต่ละเดือน ก่อนแสดงอัตรา แต่ต้นทาง44แถวมีรายงานเฉพาะบางหน่วย/เดือน จึงไม่ผ่านเงื่อนไขเดือนใดเลย ไม่ใช่ข้อมูลหายหรือ API ขัดข้อง

แก้ CD/NCD ให้คำนวณอัตราจากรายการโรคที่ได้รับ / ประชากรพื้นที่ทั้งหมดที่เลือกในปีเดียวกัน พร้อมข้อความว่ายังไม่ยืนยันรายงานครบทุกหน่วย/เดือน ไม่เติมรายการขาดเป็น0 เดือนว่างยังเว้นช่วงเส้น และฐานประชากรขาดยังแสดง — หน่วยไม่มีพื้นที่ N/A

ตรวจผ่าน REST สาธารณะข้อมูลจริงปี2569: ประชากร51561 วัณโรค35=67.88 ไข้หวัดใหญ่20=38.79 อาหารเป็นพิษ7=13.58 ไข้เลือดออก6=11.64 โควิด/มือเท้าปากเป็นศูนย์จริงตามแถวต้นทาง ตรงภาพเดิม

เพิ่มกล่องรวมและกล่องรายโรคด้านบน NCD/CD ทุกกล่องใช้โมเดลเดียวกับกราฟ/ตารางและตัวกรองปี/ช่วง/หน่วย/จำนวน-อัตรา กดกล่องโรคกรองกราฟ/ตาราง กดกล่องรวมคืนทุกโรค ระหว่างเลือกโรค กล่องรวมแสดงรวมโรคที่เลือก ไม่มีการเพิ่มตารางหรือแก้ข้อมูลจริง
