# บุคลากรและรูปภาพ — Ver.1.11

เพิ่มเมนูบุคลากรในเว็บจริง แสดงผู้อำนวยการกองสาธารณสุขและสิ่งแวดล้อมและหัวหน้าฝ่ายบริการสาธารณสุขในระนาบเดียวกันบน PC แยกเป็นการ์ดเต็มแถวบนจอเล็ก มีมุมมองผังและรายชื่อ ค้นหา/กรองหน่วย/วิชาชีพ ตัวอักษรในการ์ดใหญ่ขึ้น และมีขนาดทั้งเว็บ 175%/200%

นำเข้ารายชื่อที่ active จาก compensation 61 รายใน 8 หน่วย ด้วยสคริปต์อ่านอย่างเดียว scripts/export-personnel.php ใช้เฉพาะชื่อ ตำแหน่ง ระดับ ประเภทบุคลากรและรหัสหน่วย เก็บไฟล์เตรียมนำเข้าใน backups ที่ถูก ignore และไม่รวมในเว็บ รายชื่อเริ่ม published=false เพื่อให้ ADMIN ตรวจและเลือกเผยแพร่ ไม่มีการแก้ไขฐานข้อมูล compensation และไม่ได้คัดลอกบัญชี/รหัสผ่านเดิม

ตารางเพิ่ม 2 ตาราง: hp_personnel, hp_personnel_accounts (รวม hp_* 17 ตาราง) ตารางบัญชีเชื่อมบุคลากรอ่านได้เฉพาะเจ้าของหรือ ADMIN และแก้ได้เฉพาะ ADMIN หนึ่งบัญชีเชื่อมได้หนึ่งคน แยกจากข้อมูลสาธารณะ

ADMIN เพิ่ม/แก้รายชื่อ ระบุตำแหน่งผู้อำนวยการ/หัวหน้าฝ่าย เปิดเผยแพร่ และเชื่อมบัญชี USER โดย UUID จากบัญชีที่สร้างในเมนูจัดการข้อมูลได้ STAFF อัปโหลดภาพเฉพาะหน่วยที่ได้รับมอบหมาย USER ที่ไม่มีสิทธิ์หน่วยอัปโหลดภาพเฉพาะตนเองหลังเชื่อมบัญชี ไม่ให้ USER/STAFF เปลี่ยนชื่อ หน่วย สถานะเผยแพร่ หรือเชื่อมบัญชีเอง การสร้าง USER ไม่เพิ่ม hp_user_facilities และคง profiles.active=false ไม่ให้สิทธิ์แอปอื่น

กดรูปเลือก JPEG/PNG/WebP ต้นฉบับไม่เกิน 10 MB จากนั้น re-encode ผ่าน canvas เป็น WebP กรอบสูงสุด 400×500 px ไม่ขยายภาพเล็ก ลบ EXIF โดยการสร้างภาพใหม่ บีบอัดเป้าหมายไม่เกิน 100 KiB พื้นที่ Storage private hp-personnel จำกัด image/webp และ 128 KiB ฝั่งเซิร์ฟเวอร์ RLS บังคับไฟล์ชื่อ UUIDบุคลากร.webp เพียงหนึ่งไฟล์ต่อคน upsert แทนภาพเก่า ไม่มีการสะสมรุ่นภาพ เก็บ photo_bytes จาก metadata จริงใน Storage ผ่าน RPC ที่ตรวจสิทธิ์ก่อนอัปเดต ผู้ชมรับ signed URL อายุ 5 นาทีเฉพาะภาพที่เผยแพร่ รูปที่พักแสดงให้ผู้มีสิทธิ์เท่านั้น URL ที่ลงนามก่อนพักอาจยังใช้ได้จนหมดอายุ 5 นาที

61 รูปมีขนาดเป้าหมายรวมสูงสุดประมาณ 5.96 MiB (เพดานฝั่ง Storage 7.63 MiB) ตอนส่งมอบยังไม่มีภาพจริงอัปโหลด ไม่ต้องอาศัย paid image-transformation service ค่าใช้พื้นที่นี้ไม่รวมส่วนอื่นในโครงการ Supabase

การติดตั้งบันทึกผ่าน migrations hospital_profile_personnel_scoped_photos, hospital_profile_photo_rpc_private_guard, hospital_profile_personnel_public_read_guard; docs/hp-personnel.sql รวม schema สุดท้าย ใช้เป็นเอกสาร ไม่รันซ้ำบนฐานข้อมูลที่ติดตั้งแล้ว
