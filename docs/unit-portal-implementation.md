# หน้าเฉพาะหน่วย Ver.1.12

เมนูหน่วยบริการอยู่ใต้ภาพรวมองค์กร แสดงการ์ด 8 หน่วย หน้าเฉพาะหน่วยเปิดด้วย #unit/06117/home และมี home/services/team/performance/resources/contact/manage ลิงก์เปิดตรงและ reload คงรหัสหน่วย สลับตัวกรองหน่วยจะเปลี่ยน URL ด้วย เมนูข้อมูลหน่วยบริการเดิมไม่แสดงซ้ำใน sidebar แต่ #profile เดิมยังเปิดได้ และข้อมูลเดิมอยู่แท็บข้อมูลหน่วยและทรัพยากร

ใช้บริการและข้อมูลสำหรับประชาชนแทนข่าว ไม่มีการเชื่อม feed ข่าวหรือเพิ่มกิจกรรม ไม่มีการใส่เวลาทำการ เบอร์โทร หรือบริการสมมติ ข้อมูลที่ยังไม่เผยแพร่ไม่แสดงบนหน้าแรก ข้อมูลการติดต่อและบริการแสดงเฉพาะ hp_unit_public_info.published=true

เพิ่ม 1 ตาราง hp_unit_public_info (รวม hp_* 18 ตาราง) เพื่อเก็บเฉพาะข้อมูลประชาชนของหน่วย: ที่อยู่ โทรศัพท์ เวลาเปิด แผนที่ https บริการแบบข้อความ วันเวลา และการเตรียมเอกสาร รับสูงสุด 20 บริการ และจำกัดขนาด/รูปแบบ JSON ฝั่งฐานข้อมูล มี RLS แยกหน่วย STAFF บันทึกได้เฉพาะหน่วยที่รับมอบหมายและต้องบันทึกเป็นร่าง ADMIN ตรวจและเลือกเผยแพร่ USER ไม่มีสิทธิ์แก้ข้อมูลหน่วย ฟอร์มร่างที่ STAFF แก้จากฉบับเผยแพร่จะพักแสดงจน ADMIN เผยแพร่อีกครั้ง ไม่มีประวัติฉบับแยก; Audit เดิมบันทึกการแก้ไข

ผลงานกรอง HDC เดิมตาม facility_code และเคารพการซ่อน KPI ปี/ช่วงเวลา ค่าศูนย์จริงยังแสดง ไม่มีข้อมูลไม่สร้างค่าทดแทน บุคลากรกรองหน่วยและสถานะเผยแพร่ ไม่ทำสำเนาภาพซ้ำ แท็บบุคลากรของหน่วยเป็นมุมมองอ่าน หากต้องเปลี่ยนภาพให้ไปเมนูบุคลากรเดิมตามสิทธิ์ ADMIN/STAFF/USER ข้อมูลทรัพยากร/งบใช้ Hospital Profile เดิมกรองหน่วย หน่วย 45030 คงประชากรพื้นที่เป็น N/A

การติดตั้ง: migrations hospital_profile_unit_public_info, hospital_profile_unit_service_shape_validation; schema เริ่มต้นบันทึก docs/hp-unit-public-info.sql; ใช้ร่วมกับการตรวจ JSON ล่าสุดใน migration

ตรวจฐานข้อมูลจริงใน transaction แล้ว rollback: STAFF บันทึกร่างของตนได้ เผยแพร่เองไม่ได้ เพิ่มข้อมูลอีกหน่วยไม่ได้ และผู้ชมทั่วไปอ่านร่างไม่ได้ ไม่มีข้อมูลทดสอบค้างในตาราง ตรวจ UI fixture ด้วย scripts/unit-ui-check.mjs: เมนู/8หน่วย/ลิงก์ตรง/reload/การสลับหน่วย/บริการไม่ปะปน/STAFFร่าง-ADMINเผยแพร่/ปฏิเสธจัดการข้ามหน่วย และ 144 viewport checks ที่ 100/200% ไม่เขียนข้อมูลจริงลงฐานข้อมูล

เริ่มใช้งาน: เข้าสู่ระบบ → หน่วยบริการ → เลือกหน่วย → จัดการข้อมูลหน่วย → กรอกข้อมูลบริการและติดต่อจริง → STAFF บันทึกร่าง → ADMIN ตรวจและเลือกยืนยันและเผยแพร่ ในรายการบริการกรอกหนึ่งบริการต่อบรรทัด: ชื่อบริการ | วันเวลา | ขั้นตอนหรือเอกสาร ใช้ช่องที่ไม่ทราบเป็นว่าง ระบบไม่เติมเวลาให้เอง
