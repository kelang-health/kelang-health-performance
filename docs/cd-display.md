# โรคติดต่อ Ver.1.14

ปรับตามภาพผู้ดูแล: กราฟเส้นแนวโน้มโรคติดต่อรายเดือนอยู่ด้านบน และกราฟแท่งยอดสะสมแยกตามโรคเรียงจำนวนมากไปน้อยอยู่ด้านล่าง พร้อมตัวเลขทุกจุดจริงและตารางรายหน่วย/รายเดือน สลับจำนวนและอัตราต่อ100,000คนได้ทั้งสองกราฟ

คงตัวกรองปีงบประมาณ หน่วย พื้นที่ และไตรมาส อัตราใช้ประชากรพื้นที่ปีเดียวกันและผลรวมตัวตั้ง/ตัวหาร ไม่เฉลี่ยอัตรารายหน่วย หน่วยไม่มีพื้นที่แสดง N/A อัตราขาดฐานประชากรหรือโรคไม่มีรายงานในหน่วยที่เลือกแสดง — เดือนขาดข้อมูลไม่มีจุดหรือเส้นเชื่อมข้ามช่องว่าง ศูนย์ต้นทางแสดงจุด0 ไม่มีการเติมเดือนที่ยังไม่รายงาน

สะสมเป็นจำนวนตามข้อมูลโรคในช่วงที่เลือก ไม่ใช่บุคคลไม่ซ้ำ หากรายงานเดือนใดขาด ยอดสะสมคือเฉพาะข้อมูลที่ได้รับ ไม่ได้ยืนยันครบทุกเดือน ไม่มีการเพิ่มตารางหรือแก้ข้อมูลผู้ป่วย
