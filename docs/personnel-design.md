# ต้นแบบหน้าบุคลากร

ต้นแบบ: docs/personnel-design.html (ข้อมูลตัวอย่าง ไม่ได้เชื่อมฐานข้อมูล)
อ้างอิงรูปแบบ https://health.lp-pao.go.th/doph_system/main/pages/doc_structure.php

ออกแบบผังหัวหน้างาน → หน่วยบริการ → การ์ดบุคลากร พร้อมภาพด้านซ้ายชื่อ มีรายชื่ออีกมุมมอง ค้นหาและกรองหน่วยบริการ/วิชาชีพ รองรับมือถือและแท็บเล็ต

แหล่งข้อมูลที่ตรวจ: compensation_personnel ใน D:/AppServ/www/compensation/schema.sql
ใช้ prefix + full_name, position_name, position_level, employment_type, current_facility, facility_code และ active เท่านั้นสำหรับรายการเผยแพร่ ไม่มีช่องภาพใน schema ปัจจุบัน หน้า personnel.php ใช้อักษรย่อแทนภาพ

ระยะนำไปใช้จริง: อ่านข้อมูลผ่านตัวส่งออกที่กำหนดรายการช่องอนุญาตและตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ ไม่เปิด MySQL ให้เบราว์เซอร์ เชื่อมด้วยรหัสบุคลากรต้นทางและ facility_code เก็บภาพ/ลำดับ/ผู้บังคับบัญชา/การเผยแพร่แยกใน Hospital Profile ให้ ADMIN ตรวจและอนุมัติรายชื่อก่อนเผยแพร่ ไม่ส่งเลขบัตรประชาชน เงินเดือน บัญชีธนาคาร หรือข้อมูลสิทธิ์ compensation มาเว็บสาธารณะ

ต้นแบบยังไม่ได้เพิ่มตารางหรืออ่านข้อมูลบุคคลจริง และยังไม่ได้ยืนยันลำดับบังคับบัญชา การจัดกลุ่มตัวอย่างไม่ใช่ผังองค์กรจริง

กราฟ 1.10: กราฟแท่งแทนเส้น คงค่าจริง/ค่าว่างและแสดงตัวเลขทุกแท่ง เพิ่มกราฟร้อยละเบิกจ่ายพร้อมเส้นเป้าหมายบริหาร 80% ตามภาพผู้ดูแล เส้นนี้ไม่ใช่เป้าหมาย HDC และไม่เพิ่มเป้าจำนวนบาทที่ไม่มีนิยาม
