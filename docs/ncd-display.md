# NCD Ver.1.13

หน้าโรคเรื้อรังใช้กราฟแท่งคู่รายเก่า/รายใหม่ สีฟ้า/ชมพู ตัวเลขบนแท่ง เรียงตามจำนวนรวมมากไปน้อย และกราฟโดนัทพร้อมคำอธิบายจำนวน/ร้อยละทุกโรค ตารางรายหน่วยมีผลรวม คลิกชื่อหน่วยเพื่อกรองกราฟ สลับจำนวน/อัตราต่อแสนได้

คงสูตรต้นทาง: รายเก่าใช้ค่าสูงสุดในปี + รายใหม่รวมเฉพาะช่วงที่เลือก ผลรวมข้ามโรคเป็นรายการโรค ไม่ใช่บุคคลไม่ซ้ำ โดนัทใช้จำนวนตามข้อมูลโรคเสมอและระบุชัดเจน ไม่ใช่สัดส่วนอัตราป่วย

อัตราใช้ประชากรพื้นที่ปีเดียวกัน หน่วยไม่มีพื้นที่แสดง N/A และไม่รวมในภาพรวม อัตราภาพรวมใช้จำนวนรวม/ประชากรรวม ไม่เฉลี่ยอัตรารายหน่วย หากประชากรหาย/เป็นศูนย์ หรือโรคขาดในหน่วยที่เลือก จะแสดง — ไม่สร้างศูนย์แทนข้อมูลขาด

เปลี่ยนเฉพาะการแสดงผล ไม่มีตารางหรือข้อมูลผู้ป่วยเพิ่ม ตรวจ 35 tests และ UI fixture สลับโหมด/เจาะหน่วย/มือถือ-แท็บเล็ต-PC/ตัวอักษร100–200% 12ชุด ไม่มีข้อมูลทดสอบลงฐานจริง
